# FoodZyn `.github`

Organization-wide defaults for every FoodZyn repository.

| Path | Purpose |
|---|---|
| `profile/README.md` | The public profile shown on <https://github.com/FoodZyn> |
| `CONTRIBUTING.md` | How we branch, commit, review and merge |
| `CODE_OF_CONDUCT.md` | How we treat each other |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to ask questions |
| `ISSUE_TEMPLATE/` | Default issue forms (bug, feature, user story) |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request description |
| `AGENTS.md`, `CLAUDE.md` | Rules for people and agents in this repository |

A repository that has its own file of the same kind uses that one instead.

This repository is public so the profile can be shown. Do not put internal
information here.
